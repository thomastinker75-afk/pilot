# Add official visuals to every checklist step

## What will change
- Add a visual area beside each checklist section on larger screens and directly below its heading on phones.
- Use only current visuals from official Apple, Google, YouTube, Meta, TikTok, Snap, and Discord sources.
- Match each visual to the exact setting being explained: account setup, time limits, purchases, content controls, communications, location, autoplay, history, Shorts, recommendations, privacy, messaging, and reporting.
- Keep every visual linked to its original official guide or video, with the organisation and a short description shown beneath it.
- Where an official still image is unavailable, use the official video thumbnail as a clearly labelled “Watch official walkthrough” visual rather than recreating the interface.

## Safeguards
- Do not invent, redraw, or simulate app screens.
- Store reusable official assets locally so checklist visuals remain stable; retain source attribution and links.
- Avoid visuals that expose personal account details or are too old to match the written instructions.
- Preserve the current wording and menu paths except where an official source proves a correction is needed.

## Technical details
- Extend checklist sections with optional visual metadata: local image, alt text, source name, source URL, and visual type.
- Add a reusable accessible visual panel to the checklist detail page.
- Use responsive two-column section layouts without nesting cards.
- Add complete route metadata for the checklist detail page while preserving its dynamic title and description.
- Verify the four practical checklists on desktop and phone sizes, including image loading, source links, and compilation.
